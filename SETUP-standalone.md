## Инструкции для Claude Code

Ты помогаешь разработчику подключиться к приватному репозиторию `dmtrpvl-sys/cdek` на GitHub и загрузить туда код JD-коннектора. Выполни шаги по порядку. Перед каждым шагом сообщай что делаешь.

### Шаг 1 — Настрой git (если не настроен)

```bash
git config --global user.name
git config --global user.email
```

Если пусто — спроси имя и email, затем:
```bash
git config --global user.name "ИМЯ"
git config --global user.email "EMAIL"
```

### Шаг 2 — Проверь SSH-доступ к GitHub

```bash
ssh -T git@github.com
```

Если ответ содержит "successfully authenticated" — хорошо, продолжай.
Если ошибка — сообщи: «Нужно настроить SSH-ключ. Скажи мне и я помогу».

### Шаг 3 — Клонируй репо

```bash
ls ~/CDEK 2>/dev/null && echo "уже есть" || git clone git@github.com:dmtrpvl-sys/cdek.git ~/CDEK
```

### Шаг 4 — Найди код JD-модуля

Спроси пользователя: «Где на компьютере лежит папка с кодом JD-коннектора? Напиши полный путь.»

Покажи содержимое и подтверди: «Это тот код?»

### Шаг 5 — Перенеси код

```bash
cp -r ПУТЬ_К_КОДУ/. ~/CDEK/connector/
ls ~/CDEK/connector/
```

### Шаг 6 — Забери последние изменения

```bash
cd ~/CDEK && git pull
```

### Шаг 7 — Закоммить и запушить

```bash
cd ~/CDEK
git add connector/
git status
```

Покажи список файлов, подтверди с пользователем, затем:
```bash
git commit -m "add: JD connector module initial code"
git push
```

### Шаг 8 — Сообщи о завершении

«Готово! Код загружен в репо. Для дальнейшей работы:
- Перед началом: скажи мне `забери последние изменения`
- После работы: `закоммить и запушить изменения с сообщением "..."`»
