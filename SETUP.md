# Инструкция для Claude Code — подключение к репо CDEK

> **Менеджеру:** открой этот файл и скажи Claude Code:
> `"Прочитай SETUP.md и выполни все шаги по порядку"`

---

## Инструкции для Claude Code

Ты помогаешь разработчику подключиться к репозиторию `dmtrpvl-sys/cdek` и загрузить туда код JD-коннектора. Выполни шаги по порядку. Перед каждым шагом сообщай что делаешь. Если нужны данные от пользователя — спроси.

---

### Шаг 1 — Настрой git (если не настроен)

Проверь командой:
```bash
git config --global user.name
git config --global user.email
```

Если пусто — спроси у пользователя имя и email, затем выполни:
```bash
git config --global user.name "ИМЯ"
git config --global user.email "EMAIL"
```

---

### Шаг 2 — Проверь SSH-доступ к GitHub

```bash
ssh -T git@github.com
```

Ожидаемый ответ: `Hi USERNAME! You've successfully authenticated`

Если ошибка — сообщи пользователю: «Нужно настроить SSH-ключ для GitHub. Скажи мне и я помогу».

---

### Шаг 3 — Клонируй репо (если ещё не склонировано)

Проверь есть ли папка `~/CDEK`:
```bash
ls ~/CDEK
```

Если нет — клонируй:
```bash
git clone git@github.com:dmtrpvl-sys/cdek.git ~/CDEK
```

---

### Шаг 4 — Найди код JD-модуля

Спроси у пользователя: «Где на твоём компьютере лежит код JD-коннектора? Напиши полный путь к папке.»

Когда получишь путь — покажи содержимое:
```bash
ls -la ПУТЬ_К_КОДУ
```

Подтверди с пользователем: «Это тот код? Переношу в ~/CDEK/connector/»

---

### Шаг 5 — Перенеси код в connector/

```bash
cp -r ПУТЬ_К_КОДУ/. ~/CDEK/connector/
```

Проверь результат:
```bash
ls ~/CDEK/connector/
```

---

### Шаг 6 — Забери последние изменения из remote

```bash
cd ~/CDEK && git pull
```

---

### Шаг 7 — Закоммить и запушить

```bash
cd ~/CDEK
git add connector/
git status
```

Покажи пользователю список файлов. Если всё верно — коммить:

```bash
git commit -m "add: JD connector module initial code"
git push
```

---

### Шаг 8 — Готово

Сообщи пользователю:
«Код успешно загружен в репо `dmtrpvl-sys/cdek` в папку `connector/`.
Дима увидит его на GitHub. Для дальнейшей работы:
- Перед началом работы всегда говори мне: `забери последние изменения`
- После завершения: `закоммить и запушить изменения с сообщением "..."`»
